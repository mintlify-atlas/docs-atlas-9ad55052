Viajes AJT is a full-stack PHP travel agency web platform built on a custom MVC architecture. It enables customers to browse tour packages, make reservations with multiple payment methods, and request visa advisory services — while giving administrators complete control over inventory, bookings, users, and financial reporting.

## Platform Overview

Viajes AJT is organized into two distinct areas:

**Customer-facing site** — a public storefront where visitors can explore travel packages by destination and category, view detailed itineraries and pricing, book directly online, and track their reservations from a personal profile.

**Admin back-office** — a protected panel (role `id_rol = 2`) where administrators manage the full package catalog, process reservations, oversee visa advisory requests, promote users, and download sales reports.

<Steps>
  <Step title="Deploy the application">
    Clone the repository, point your Apache virtual host at `public/` as the document root, and enable `mod_rewrite`. See [Installation](/installation) for full steps.
  </Step>
  <Step title="Configure the database">
    Create the MySQL database using `database/schema.sql`, seed demo data with `database/seed.sql`, and update credentials in `app/Config/LocalConfig.php`. See [Configuration](/configuration).
  </Step>
  <Step title="Browse the catalog">
    Visit `/catalog` to see all available tour packages. Use the search endpoint `GET /api/paquetes/buscar` for live filtering. See [Tour Catalog](/features/catalog).
  </Step>
  <Step title="Make a booking">
    Select a package, choose travel date and passenger count, then complete the checkout form at `/checkout`. Payments can be made by card, Yape/Plin QR, or bank transfer. See [Booking & Checkout](/features/booking).
  </Step>
</Steps>
