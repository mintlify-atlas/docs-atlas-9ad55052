Viajes AJT is a complete, dependency-free travel agency web application built in PHP 8 on a custom MVC framework. It powers the full customer journey — from browsing tour packages and booking travel to requesting visa advisory services — alongside a back-office admin panel for managing inventory, reservations, users, and financial reporting.

## Platform roles

Viajes AJT has two distinct user roles, each with a different experience:

| Role | `id_rol` | Default redirect after login | Access |
|---|---|---|---|
| **Client** | `1` | `/` (home) | Public catalog, booking checkout, profile, visa requests |
| **Administrator** | `2` | `/admin/dashboard` | All client features + full back-office panel |

<Note>
Administrators are created from the Users section of the admin panel at `/admin/usuarios`. The first admin account must be seeded directly via `database/seed.sql` or by manually inserting a user with `id_rol = 2`.
</Note>

## Technology stack

| Layer | Technology |
|---|---|
| Language | PHP 8.0+ |
| Architecture | Custom MVC, PSR-4 autoloader, no Composer |
| Database | MySQL 5.7+ / MariaDB 10.4+, PDO with prepared statements |
| Web server | Apache with `mod_rewrite` |
| Frontend | Vanilla JS + jQuery 3.7.1, CSS custom properties (design tokens) |
| Session | PHP native sessions (`VIAJESAJTSESSID`) |
| Security | CSRF tokens, bcrypt passwords, MySQL rate limiting, HTTP security headers |
